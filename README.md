## What I've been building

### [AquaGuard](https://github.com/Vvedika05/AquaGuard)
**Water quality classification | Machine Learning | Streamlit**

An end-to-end application that explores water-quality data and predicts potability.

- Built a classification pipeline and compared machine learning models.
- Evaluated model performance using cross-validation and held-out test data.
- Saved the trained pipeline and built an interactive Streamlit application.
- Added simulated real-time monitoring to demonstrate how predictions could be used.

**Stack:** Python · Pandas · scikit-learn · Streamlit · Joblib

[Repository](https://github.com/Vvedika05/AquaGuard) · [Live application](https://aquaguard-ml.streamlit.app/)

### WorkHub AI
**Department management platform | Full-stack development | AI-assisted knowledge retrieval**

A team capstone project exploring how a department can manage information that is otherwise scattered across emails, messages, documents, and shared drives.

The platform brings announcements, meetings, documents, tasks, faculty information, and department knowledge into one place. We're also working on a conversational assistant that can answer questions using department documents.

- Working on backend and database infrastructure.
- Built a PDF ingestion flow with text extraction and chunking.
- Explored embedding generation and department-scoped semantic retrieval.
- Working towards relevance ranking and source-cited answers in the conversational assistant.

**Stack:** Next.js · Tailwind CSS · Supabase · PostgreSQL · Google Gemini · pgvector · Vercel

*Work in progress.*
